# 빨리 · 무응답 — 아들 영상 시간 관리 앱

아이의 무응답 습관과 보호자의 "빨리"라는 말버릇을 함께 관리하기 위해 만든 가정용 영상 시청 시간 관리 웹앱입니다.

## 🔗 바로 열기
- **https://shin-navy.vercel.app/**

별도 설치 없이 위 주소로 접속하면 바로 사용할 수 있어요. (폰, 갤럭시 워치 브라우저 모두 지원)

## 📌 이 앱을 만든 이유
아이가 대답을 잘 하지 않는 습관을 고쳐주고 싶어 "무응답 시 1분 삭감" 규칙을 세웠는데, 매번 기억하고 기록하기 번거로워 정확하게 관리할 방법이 필요했습니다. 또한 저 자신도 아이에게 "빨리"라는 말을 자주 해서 안 좋은 영향을 줄 수 있다고 느껴, 그 말을 하면 1분을 주는 규칙도 함께 만들었습니다. 서로에게 스트레스가 되던 부분을 위트 있는 게임으로 바꿔, 즐겁게 서로의 습관을 고쳐나가고자 이 앱을 만들었습니다.

## ✨ 주요 기능
| 기능 | 설명 |
|---|---|
| 남은 시간 표시 | 이번 주 남은 시간을 큰 숫자와 진행 막대로 표시 |
| 🐶 빨리 버튼 | 누를 때마다 1분 추가 (상한 없음) |
| 🐱 무응답 버튼 | 누를 때마다 1분 삭감 (0분까지) |
| 누적 횟수 표시 | 이번 주 "빨리"/"무응답" 각각 누른 횟수 표시 |
| 주간 자동 초기화 | 매주 월요일, 남은 시간(4시간 30분)과 횟수 자동 리셋 |
| 설정 비밀번호 보호 | 4자리 비밀번호로 설정 화면 잠금 |
| 시간 직접 설정 | 설정 화면에서 남은 시간을 원하는 값으로 바로 수정 가능 |
| 폰 · 워치 겸용 화면 | 폰(사각형)과 갤럭시 워치(원형) 각각에 맞춘 화면 제공 |

## 📁 파일 구성
- `index.html` — 워치(원형 화면)용 메인 버전, 이 저장소의 실제 배포 파일
- `phone.html` — 폰(가로 화면)용 버전

## 🛠 기술 스택
HTML5 / CSS3 / Vanilla JavaScript, Web Storage API(localStorage), Web Crypto API(SHA-256 비밀번호 해시), GitHub, Vercel(자동 배포)

## ⚠️ 알아두면 좋은 점
- 폰과 워치는 각 기기 브라우저에 데이터를 따로 저장하기 때문에, 자동으로 동기화되지는 않아요. 값이 다르면 설정 화면의 "시간 직접 설정"으로 맞춰주면 돼요.
- 기본 비밀번호는 `1506`이며, 앱 안의 설정 화면에서 언제든 바꿀 수 있어요.
